# 跨板块事件怎么拆

同一条消息可能对应不同的供给、需求和物流变化。先写已经发生的事，再按品种追踪影响，最后比较价格是否已经反映。

| 事件 | 要核对的事实 | 继续查哪里 |
|---|---|---|
| 航路或地缘冲突 | 哪段航路、哪种船货、实际中断和持续时间 | 原油的可交付供应、欧线的周转与货量、黄金的资金需求分别查 |
| 能源成本变化 | 哪种能源、哪个地区、执行时间与替代成本 | 冶炼、化工、化肥的实际装置和成本路径 |
| 建筑与制造政策 | 实施对象、落地日期、订单和产量 | 成材需求、钢厂生产、矿焦采购、玻璃纯碱库存 |
| 天气与农业 | 作物年度、产区、面积与品质 | 产量、上市节奏、出口、到港及加工分别查 |
| 利率或流动性变化 | 首次公布时间、曲线与资金价格 | 黄金、股指、不同久期国债分别解释 |

写判断时保留四项：已有证据、传导假设、可能反证、下一次检查。只看到消息而缺乏价格和产业数据时，把缺口列出来。不同品种允许给出不同结论，方向未知就记录未知。

作者曾补充过不同阶段的金油与 EC 观点，这些回顾保留在专题仓库的方法文件中。缺乏同期记录的回忆不作为本 Skill 的胜率样本，也不作为当前默认方向。
