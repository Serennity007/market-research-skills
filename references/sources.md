# 官方入口与资料口径

整理日期：2026-10-25。目录是研究分组，不是交易所最新全品种清单；下面用于核对品种身份和寻找目标时点文件。交易参数、挂牌与活跃合约要另查，没有把旧版手册参数写进程序。

- [上期所产品规则目录](https://www.shfe.cn/regulation/exchangerules/productrules/) 与 [上市品种入口](https://www.shfe.com.cn/)：金属、能源化工及相关品种身份。
- [上期能源集运欧线入口](https://www.ine.cn/products/futures/index_f/ec_f/)：EC 产品与规则；本次访问遇到人机验证。
- [大商所](https://www.dce.com.cn/)：产品、交易数据、仓单与交割规则；本次首页访问超时。
- [郑商所](https://www.czce.com.cn/) 与 [2025年品种资料](https://www.czce.com.cn/cn/rootfiles/2025/07/04/1750859895384730-1750859895409197.pdf)：品种身份与历史规则线索；首页访问受限，历史参数未作当前参数使用。
- [广期所碳酸锂合约页面](https://www.gfex.com.cn/gfex/sytslqhhy/202307/9ad927b8ec4c458594e172fd1ada2a9b.shtml)：LC 身份；页面为历史版，不据此固定当前保证金。
- [中金所](https://www.cffex.com.cn/)：IF/IH/IC/IM、TS/TF/T/TL 的产品与目标合约规则；本次部分产品页访问失败。
- [上海航运交易所](https://www.sse.net.cn/indices/)：SCFIS/SCFI 口径与公布资料。
- [FRED DFII10](https://fred.stlouisfed.org/series/DFII10)：10年通胀保值国债收益率口径，核对日期与版本。
- [EIA 周度石油报告](https://www.eia.gov/petroleum/supply/weekly/)：区分统计周、公布日期与修订。
- [UNCTAD 2025海运报告](https://unctad.org/system/files/official-document/rmt2025_en.pdf)：航运传导机制参考，不作为当前 EC 涨跌证明。

页面打不开时记录访问失败，继续整理可知资料；不要据此宣称已核验目标合约最新参数。公开仓库不含私人聊天原文、来源人物身份或私人文件路径。
