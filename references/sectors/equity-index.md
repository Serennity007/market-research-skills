# 股指

本组品种：IF 沪深300 CFFEX；IH 上证50 CFFEX；IC 中证500 CFFEX；IM 中证1000 CFFEX。

板块报告比较的是所选 IF/IH/IC/IM 固定合约的价格变化。现货指数风格和成分宽度请结合股指专题 Skill。套保手数需要 beta、实际敞口、乘数和成本，此报告不从涨跌幅直接生成。

## 先查什么

- 区分股指期货、现货指数和 ETF，具体月份及同一时点价格分别保存。
- 检查权重/等权、大小盘、行业和市场宽度，说明成分覆盖。
- 期现基差与套保需要分红、到期、乘数和实际风险暴露资料。

## 写一条可以复查的判断

写明研究品种与合约、数据截止时刻，列出已观察到的价格和产业数据。再写解释：哪段供给或需求发生了什么变化，哪些新资料会支持或推翻它。

价格结构按 [多周期与关键位方法](../price-structure.md) 检查；同一价格序列的均线、MACD 和形态不能当成三份独立证据。

## 下次检查

- 核对指数上涨是否伴随成分扩散。
- 检查合约到期、分红和基差变化对期货表现的影响。

数据表保留单位、观测时间、公布时间、取数时间与来源。默认练习采用模拟数字；套用真实合约前核对 [官方入口](../sources.md) 中的目标时点规则。
