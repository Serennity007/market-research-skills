# 六个可以直接使用的研究任务

把“……”替换成实际标的、数据路径和带时区截止时间。没有数据时让代理列证据缺口，不让它补写行情。

## 1. 黄金：局部修复与宏观分歧

```text
使用 $gold-research-skill，分析……截至……的数据。
请运行结构与金银/美元/实际利率对照；若价格收复支撑但均线下降，保留两者分歧。
说明是否使用共同日期窗口，给出撤销修复假设的条件，保存 HTML/Markdown/JSON。
```

## 2. 原油：曲线是否真的变陡

```text
使用 $crude-oil-research-skill，对比……和……两次 WTI 快照。
先对齐具体合约，再比较固定合约价差；列出新增和移除合约，不把换月当成收益。
将供需解释与已计算事实分开，指出还需要哪些库存和交付证据。
```

## 3. 欧线：绕航会不会被需求下降抵消

```text
使用 $ec-shipping-research-skill，研究 EC……，截止……。
输入我提供的往返周期、额外天数、受影响基准运力占比与需求变化，计算三套情景。
同时比较当时已公布 SCFIS 与期价，核对公布时滞；不要把相对需求压力当成 EC 涨幅。
```

## 4. 大 A：指数领先是否等于普涨

```text
使用 $a-share-index-research-skill，对照截至……的沪深300、上证50、中证500和中证1000。
同窗口比较价格收益和相对强弱，结合……成分样本的覆盖率、上涨比例和成交集中度。
分别说明官方指数、样本等权与股指期货的口径，不把部分样本说成全市场。
```

## 5. 冲突事件：跨市场对照

```text
分别使用黄金、原油与欧线 Skill，统一数据截止时间……，分析我提供的事件和数据。
分别拆解黄金资金需求、原油实际供给/物流、欧线有效运力与货量传导。
对每个市场写支持证据、反证和待确认事项；允许结论不同或方向未知，不生成跨市场综合买卖分数。
```

## 6. 盘后复盘：保留原计划

```text
用对应 Skill 读取旧报告……的 config.snapshot.json，先重跑确认原计算。
再用新数据……生成新的快照，逐项检查原假设、确认和失效条件是否发生。
区分方向、时机与执行；无真实成交就不计算实盘收益。保留两份原始报告与输入，不改写旧计划。
```
