# 研究和复盘怎么写

拿到数据后，先记品种、合约、单位、周期和截止时间。随后把已经观察到的现象写清楚，再写准备等什么条件。

## 一条记录的写法

下面用仓库里的黄金模拟例子说明：

```text
截止时间：2024-01-09 15:00 +08
数据：bars.csv，模拟 H4 K线
观察：前收盘98，本收盘102，回到人工支撑100上方。
同时看到：MA5 < MA10 < MA20，MACD柱值仍负、绝对值缩小。
判断：出现局部修复，继续观察后续收盘。
需要修改判断的情况：再次收盘跌破100。
还缺的资料：真实标的报价、宏观与资金需求数据。
下次记录：补新的已收盘K线，再检查100是否守住。
```

这个例子只写到当前输入能够支持的地方，后续走势留给下一条记录。

## 各品种还要补什么

黄金：对照美元和实际利率，核对金银的单位和日期；当它们与金价方向不一致时，把分歧保留下来。

原油：先核对合约有没有变化，再写价差扩大或缩小；解释库存时，说明统计周和公布时间。

欧线：把航路消息、船司报价和已公布 SCFIS 分开记；绕航情景列明往返天数、影响范围和需求假设。

股指：说明研究哪个指数、宽度样本包含多少只、缺多少只，再写大小盘表现。讨论期货时补具体合约与同期现货。

## 下一次怎么复盘

先用旧报告目录里的 `config.snapshot.json` 重跑，确认原计算。再换新数据生成新报告，逐项写原先等的条件有没有出现。

把方向、时机和执行分开讨论。方向后来走对，也需要检查当时有没有合适的确认条件；有成交记录，才核对成本和盈亏。旧报告保留，新判断另起一条。

## 给代理的任务也写具体

```text
使用 $crude-oil-research-skill，读取我提供的两份原油曲线 CSV。
前次截止时间是……，本次是……。
比较同一对合约的价差，把新增、移除的合约列出来。
保存报告，并说明还缺哪些库存和供需资料。
```

黄金、欧线和股指同样给出数据位置与截止时间。只有新闻而没有价格或指数数据时，先整理待查事项，再补数据。
